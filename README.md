# بوابة الروابط العربية

بوابة عربية حديثة وبسيطة لعرض الروابط المهمة والمساعدات في مكان واحد بشكل منظم وسهل الاستخدام.

تم تطوير المشروع باستخدام:

- React
- Tailwind CSS

## المميزات

- تصميم عربي RTL
- واجهة بسيطة وسريعة
- بحث وتصفية الروابط
- تصنيفات منظمة
- تصميم متجاوب لجميع الأجهزة
- دعم الروابط الرسمية والمميزة
- سهولة إضافة وتعديل الروابط

## مكان حفظ الروابط

جميع الروابط موجودة داخل الملف:

```text
src/data/links.js
```

## التصنيفات

- رسمي
- مساعدات غذائية
- تحديث بيانات
- ترميم وإيواء
- أيتام
- أطفال وذوي إعاقة
- مؤسسات خيرية
- روابط عامة

## الأيقونات

يتم استخدام مكتبة:

```text
lucide-react
```

ويمكن تعديل الأيقونات من خلال:

```text
src/utils/icons.jsx
```
